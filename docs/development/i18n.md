# Qt application translations

Qt embeds Simplified Chinese translations from
`apps/aigle/translations/aigle_zh_CN.ts`, including Qt's standard dialogs.
Preferences → Language selects system, English, or Simplified Chinese. The
choice is stored in Qt settings as `preferences/language`; it currently applies
on restart. File names, user-provided names, metadata values and engine error
details are not translated.

Use `tr()` for static UI text and `aigle::uiText()` for schema/layout labels.
List dynamic labels in `apps/aigle/src/translation_labels.hpp` using
`QT_TRANSLATE_NOOP` so extraction retains them. Keep stable values in combo-box
item data; never serialize translated display labels as parameter values.

Update the catalog with Qt's `lupdate apps/aigle/src -no-obsolete -ts
apps/aigle/translations/aigle_zh_CN.ts`, translate new entries, and build with
CMake. LinguistTools and Qt's Chinese qtbase translation catalog are build
requirements. Preserve numbered placeholders, file-filter patterns and markup.
