# Application translations

The UI uses [rust-i18n 4.2.4](https://docs.rs/rust-i18n/4.2.4/rust_i18n/)
and supports English and Simplified Chinese. Use **View → Language** (Chinese:
**视图 → 语言**) to switch immediately. The choice is saved in
`$XDG_CONFIG_HOME/aigle/language`, or `~/.config/aigle/language` when XDG_CONFIG_HOME
is unset. Remove that file to follow the system locale again.

Without a saved choice, startup checks nonempty `LC_ALL`, `LANGUAGE`, `LC_MESSAGES`,
then `LANG`. Chinese locales select Simplified Chinese; other locales use English.
The component library uses the same language. File names, photo data, and existing
mask names are preserved. Default names for new masks use the selected language.
Engine and operating-system error details retain their original text.

## Updating text

Catalogs live in `crates/app/locales/en.json` and `zh-CN.json`. They are flat JSON
objects whose keys are dotted paths, such as `param.light.exposure` or
`export.format.tiff16`. Keep the same keys in both catalogs. Add
`crate::i18n::t("key")` at the point where UI text is rendered; keep keys in static
definitions and cached entities untranslated so a language change can update them.

The first segment of a key names the area of the UI:

| Prefix | Used for |
|---|---|
| `common` | Buttons shared by many dialogs (`common.cancel`, `common.reset`) |
| `menu`, `toolbar` | Menu titles and the title bar |
| `action` | Commands, named after the GPUI action (`action.OpenFolder`); used by menus, the keybinding editor and history |
| `action_group` | Categories in the keybinding editor |
| `group`, `section` | Groups and sections of the develop panel |
| `param` | Slider labels, named after the edit parameter path; `param.local.*` for mask adjustments |
| `panel`, `crop`, `masks`, `retouch`, `curve_editor`, `canvas` | Text of one panel or tool |
| `history`, `history_panel` | History labels, and the history panel itself |
| `library`, `grid`, `meta`, `export`, `presets`, `copy_settings`, `keybindings`, `display`, `language` | Text of one feature |

Slider labels are not written in the code: the develop panel derives the key from the
parameter path with `panel::label_key` (`light.exposure` → `param.light.exposure`), and
the keybinding editor derives `action.<Name>` from the action name. A new slider or
action therefore only needs a catalog entry.

Use the library's `rust_i18n::t!` macro for formatted text, with named
`%{variable}` placeholders in catalog values:

```rust
rust_i18n::t!("canvas.open_failed", e = error).into_owned()
```

The catalog value is `Cannot open: %{e}` in English and `无法打开：%{e}` in Chinese.
Numeric formatting uses the library syntax, e.g. `arg0 = value : {:.1}`. Keep named
placeholders identical between translations. Tooltips with shortcuts go through
`crate::keymap::hint`, which fills `%{shortcut_<Action>}` with the current binding.
`rust_i18n::i18n!("locales", fallback = "en")` embeds the catalogs; there is no
application build script or generated formatting macro to maintain. The library owns
the current locale, which is shared with GPUI components.

## History labels

Edit history stores labels untranslated, so it can be shown in either language.
Build a label from catalog keys and user text with `crate::i18n::join`, which separates
the parts with ` · `, for example `join(&["history.preset", &preset.name])`. Use
`crate::i18n::reset_label` for a command that resets what another label names.
`crate::i18n::history_label` translates each part when the history is shown; parts
that are not catalog keys, such as preset and snapshot names, are shown as they are.
Parameter paths, file extensions, and other machine identifiers are never translated.

## Tests

Run `cargo test -p aigle-app --bin aigle-gui` for the app tests. They check locale
detection, that both catalogs have the same keys and placeholders, history
localization, and that derived keys exist. They also scan the non-test code in
`crates/app/src` and fail on a string literal that contains Chinese text, or on a
literal that looks like a catalog key but is missing from the catalog.
