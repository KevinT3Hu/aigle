# Application translations

The UI uses [rust-i18n 4.2.4](https://docs.rs/rust-i18n/4.2.4/rust_i18n/)
and supports English and Simplified Chinese. Use **View → Language** (Chinese:
**视图 → 语言**) to switch immediately. The choice is saved in
`$XDG_CONFIG_HOME/aigle/language`, or `~/.config/aigle/language` when XDG_CONFIG_HOME
is unset. Remove that file to follow the system locale again.

Without a saved choice, startup checks nonempty `LC_ALL`, `LANGUAGE`, `LC_MESSAGES`,
then `LANG`. Chinese locales select Simplified Chinese; other locales use English.
The component library uses the same language. File names, photo data, and existing
mask names are preserved. Default names for new masks use the selected language.
Engine and operating-system error details retain their original text.

## Updating text

Catalogs live in `crates/app/locales/en.json` and `zh-CN.json`. Keys are the original
Chinese strings, which keeps existing tool definitions and edit history compatible.
Keep matching keys in both catalogs. Add `crate::i18n::t("key")` at the point where
UI text is rendered; keep keys in static definitions and cached entities untranslated
so a language change can update them.

Use the library's `rust_i18n::t!` macro for formatted text, with named
`%{variable}` placeholders in catalog values:

```rust
rust_i18n::t!("无法打开：{e}", e = error).into_owned()
```

The key remains the original string for compatibility, while the catalog value is
`Cannot open: %{e}` in English and `无法打开：%{e}` in Chinese. Numeric formatting
uses the library syntax, e.g. `arg0 = value : {:.1}`. Keep named placeholders identical
between translations. `rust_i18n::i18n!("locales", fallback = "en")` embeds the catalogs;
there is no application build script or generated formatting macro to maintain.
The library owns the current locale, which is shared with GPUI components.

History labels are localized when rendered, including older Chinese labels. Unknown
labels are retained. Parameter paths, file extensions, and other machine identifiers
are never translated.

Run `cargo test -p aigle-app --bin aigle-gui` for the app tests, including locale
detection, catalog parity, format-placeholder parity, and history localization.
